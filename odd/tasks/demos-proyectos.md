# Demos de proyectos

Replace the generic home demos with six local, interactive mini versions of projects the team already built,
each stating the project it imitates and what we can build for a client.
Branch: `feat/demos-proyectos` (from `feat/portafolios-y-nosotros`, commit f5d22cb).

## Specs

- S1. User request (L1): "trabajaremos en meorar los demos trata de que sena de protyecos ya  creados y de lo que ;podemos realizar".
- S2. Decision (L2): "Demos nuevas que imiten proyectos puntuales" — each demo is a mini version of a concrete team project, names that project and its authors, and says what we can build from it ("lo que podemos realizar").
- S3. Decision (L2): "6" demos on the home page.
- S4. Decision (L2/L3): the six projects are La Lupe (menú y cotización), Emisoras Latinas (radio en vivo), Calculadora de contenedores (cálculo de carga), "UptownHair — reservas de salón", "Ocho80 + Inventario" (Ocho80 bingo digital, inventario de Entre Lanas y Fragancias).
- S5. Demos stay local simulations: no data is stored or sent, they can be reset, and the existing disclaimer "No se guardan ni se envían datos" remains.
